Jev-mail Privacy Policy

Last updated: October 26, 2026

Jev-mail is a personal email assistant built and used by Rupert Lim. It is not offered to the public. It connects only to Google accounts that belong to Rupert Lim.

What Jev-mail accesses

  • Gmail: reads messages to sort them and draft replies, applies labels, and sends emails that Rupert approves.
  • Google Calendar: reads free and busy times and creates or updates events for calls Rupert schedules.
  • Basic profile: the account's email address, to know which account is signed in.

How the data is used

The data is used only to provide Jev-mail's features to Rupert: sorting email, drafting replies, and scheduling calls. Message text may be processed by AI models to do this. The data is stored only on systems Rupert controls and is never sold, shared with other people, or used for advertising.

Google API Services User Data Policy

Jev-mail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from Google Account permissions. Stored data is deleted on request.
